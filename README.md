# Asistencia interactiva

MVP para pasar lista proyectando un estudiante a la vez.

## Uso

- **P** = Presente
- **A** = Ausente
- Al marcar una opción, avanza automáticamente al siguiente estudiante.
- Al terminar, muestra total del curso, presentes y ausentes.
- La lista de estudiantes se puede editar desde la propia página y queda guardada localmente en el dispositivo.

## Próximas etapas

La estructura está pensada para incorporar perfiles visuales individuales por estudiante: colores, intereses, iconos, sueños/proyecto de vida y fondos o animaciones.

## GitHub Pages

Para publicarlo, habilita GitHub Pages desde **Settings → Pages**, seleccionando la rama `main` y la carpeta raíz `/ (root)`.
